# Mayski Village

Новая чистая версия лендинга коттеджного поселка.

Состав:
- фотографии подключаются из `assets/img/*.webp.b64` и декодируются на клиенте;
- карта подключается из архива проекта: SVG overlay + JSON участков + фон `masterplan_bg_cropped.webp.b64`;
- старая версия сайта не используется в актуальном дереве репозитория.
