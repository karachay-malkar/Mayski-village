# Mayski Village

Чистая версия лендинга коттеджного поселка.

## Важно

- `assets/images/hero.png` — главная фотография с видом поселка.
- `assets/images/masterplan.png` — качественный PNG мастер-плана из архива проекта.
- `assets/map/masterplan_overlay_cropped.svg` — интерактивные контуры участков.
- `assets/map/masterplan_plots_cropped.json` — данные участков.

Не использовать `.webp.b64` и preview-файлы.
